# Purity 0.5.2 release notes

Purity 0.5.2 is a bug-fix release. Upgrade all Purity packages together.

## Fixed

- **Interpolations directly inside table sections.** A lone `${...}` directly
  inside `<table>`, `<tbody>`, `<thead>`, `<tfoot>`, `<tr>` or `<colgroup>`
  now compiles to a comment placeholder instead of a text placeholder. The HTML
  parser moves text out of these elements, so the old placeholder broke slot
  paths and `each()` rows inside a table section failed at mount. Code that
  added an adjacent `${null}` to work around this can remove it. This applies
  to both AOT and JIT compilation.
- **`onMount` cleanup after an unhandled error.** A component's mount callbacks
  are released even when one of them throws, so their closures are not
  retained.

## Size

The table-section fix adds 82 raw bytes to the JIT runtime compiler (Brotli
+38 to +78 bytes in the six example applications that ship it). Applications
built with strict AOT do not ship the compiler and are unaffected. All
configured size budgets pass.
